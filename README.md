# 問心羅盤

一個完全在瀏覽器本機運作的繁體中文哲學自我探索工具。沒有生成式 AI、API Key、帳號、後端或第三方追蹤程式。

## 功能

- 人際界線、工作與自我價值、選擇與不確定三條探索路徑
- 12 張人工策劃哲學觀點卡
- 依課題推薦相關書籍
- 本機課題卡、行動回顧、JSON 匯出與刪除
- PWA 離線快取、手機版與鍵盤操作
- 隨時可見的台灣心理支持資源

## 本機預覽

在此目錄執行：

```powershell
python -m http.server 4173
```

然後開啟 `http://localhost:4173`。Service Worker 需要 HTTP 或 HTTPS，直接雙擊 HTML 不會啟用離線功能。

## 檢查

```powershell
npm test
```

## 資料說明

探索文字只留在頁面；只有使用者主動保存的課題卡會寫入 IndexedDB。網站不會分析、診斷或監看自由文字，也不能取代心理師或緊急服務。
